
# MediQ — Antibiotic Usage Analyze System For Karapitiya National Hospital - Galle ,Srilanka 🏥

Dec 2024 - Present- 
🚀 After 6 months of focused development, we’re proud to introduce MediQ – Antibiotic Usage Analysis System, built for Karapitiya Hospital, Galle.

This platform is designed to address one of healthcare’s most pressing challenges – efficient and accountable antibiotic management. By combining real-time monitoring, smart analytics, and seamless workflows, MediQ empowers healthcare professionals to make data-driven decisions and optimize antibiotic use.

# 🎯 Key Highlights

Multi-tier Account Management → Secure access for admins, pharmacists & ward staff

Dynamic Antibiotic Operations → Real-time release, update & distribution control

Ward-centric Management → Centralized ward data with update capabilities

Comprehensive Drug Database → Detailed antibiotic catalog with specifications

Intelligent Stock Control → Automated inventory tracking to reduce shortages & waste

Advanced Analytics Engine → Usage insights by ward, antibiotic type & time patterns

Personalized User Profiles → Tailored experience for hospital staff

# 🔧 Tech Stack

Frontend: HTML5, Bootstrap, JavaScript (responsive UI)

Backend: PHP with MySQL (secure & reliable processing)

Deployment: Professionally hosted for 24/7 hospital access



🌐 Experience MediQ
🔗 Live: https://mediq.42web.io/karapitiya


# 🤝 Impact & Future
Built in collaboration with Karapitiya Hospital, MediQ marks a step forward in using technology to strengthen Sri Lanka’s healthcare infrastructure. Our vision is to expand this solution nationwide, supporting smarter, safer, and more sustainable hospital practices.
